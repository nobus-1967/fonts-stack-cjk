# Font Stacks Documentation

This document ([Markdown](./Fonts.md), [PDF](./Fonts)) provides a summary architectural table of font fallbacks used to ensure ideal cross-platform rendering.
Fonts are grouped by operating system type, commercial vendors, and open licenses for all key `CJK` locales (China, Japan, Korea).

The table of fonts and CSS rules include **Google Noto** family fonts (both global and regional `CJK`) and other system alternatives from **Apple** (**macOS**) or **Microsoft** (**Windows**) as well as Free **Linux** / **OFL** fonts.
